# WhatsApp Business HTTP layer

HTTP API и сервер для авторизованных WhatsApp Business сценариев в системах клиента. Проект не связан с Meta и не является официальным продуктом WhatsApp.

Назначение — согласованные бизнес-сценарии: HTTP API, серверная интеграция, сообщения, шаблоны, профили, группы, внедрение и обучение. Если у клиента есть официальная WhatsApp Business Platform или Cloud API, для соответствующих сценариев используется она.

В поставке по согласованию могут быть библиотека HTTP-запросов, HTTP-сервер, установка, настройка и обучение. Конкретные возможности, совместимость и порядок внедрения подтверждаются до начала работ.

Репозиторий — публичный листинг и документация. В нём нет коммерческого исходного кода, токенов, ключей, cookies, клиентских данных, production-конфигурации или внутренней инфраструктуры. Используются только авторизованные бизнес-аккаунты, данные владельца и разрешённые интеграции.
