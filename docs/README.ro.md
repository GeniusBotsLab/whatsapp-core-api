# WhatsApp Core API

[English](../README.md) · [Română](README.ro.md)

> **Produs comercial**

Pachet de bibliotecă și server pentru integrarea capabilităților WhatsApp printr-un API HTTP, în limitele autorizării, drepturilor de cont și regulilor aplicabile ale platformei.

## Ce include

- bibliotecă API bazată pe cereri;
- componentă de server pentru integrare HTTP;
- instalare și configurare;
- instruire pentru predarea produsului.

## Utilizare responsabilă

Integrați numai conturi, date și fluxuri pentru care există autorizare și consimțământul necesar. Nu utilizați produsul pentru spam, acces neautorizat sau ocolirea regulilor platformei.
