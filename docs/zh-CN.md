# WhatsApp Core API

> **商业产品**

一套通过 HTTP API 使用 WhatsApp 的完整库和服务器产品包。

## 包含内容

- 可直接使用的请求式 API 库。
- 用于 HTTP API 集成的服务器组件。
- 可用的 Play Integrity Token 解决方案。
- 安装与配置。
- 产品交付培训。

## 为集成而设计

该产品包可通过 HTTP 请求将 WhatsApp 功能接入您的系统。产品材料描述了通过 API 实现账号注册、消息工作流、通话、按钮、资料和群组等能力。
