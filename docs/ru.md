# WhatsApp Core API

> **Коммерческий продукт**

Готовый пакет библиотеки и сервера для работы с WhatsApp через HTTP API.

## Что входит

- Готовая библиотека API на основе HTTP-запросов.
- Серверный компонент для интеграции по HTTP API.
- Рабочее решение Play Integrity Token.
- Установка и настройка.
- Обучение при передаче продукта.

## Для интеграции

Пакет предназначен для подключения функций WhatsApp к вашим системам через HTTP-запросы. Материалы продукта описывают работу с регистрацией аккаунтов, сообщениями, звонками, кнопками, профилями и группами через API.
