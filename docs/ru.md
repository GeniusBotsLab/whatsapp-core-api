# WhatsApp Business HTTP layer

HTTP API и сервер для авторизованных WhatsApp Business сценариев в системах клиента. Проект не связан с Meta и не является официальным продуктом WhatsApp.

Навык: HTTP API, сервер, сообщения, шаблоны, профили, группы, внедрение и обучение. Если у клиента есть официальная WhatsApp Business Platform или Cloud API, для соответствующих сценариев используется она.

В поставке по согласованию: библиотека запросов, HTTP-сервер, установка, настройка и обучение. Детали совместимости и состав работ подтверждаются до внедрения.

Репозиторий — публичный листинг и документация, без коммерческого исходного кода, токенов, ключей, cookies, клиентских данных, production-конфигурации и внутренней инфраструктуры.
