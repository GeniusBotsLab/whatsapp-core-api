# WhatsApp Core API

> **商用製品**

HTTP APIを通じてWhatsAppを利用するための、完全なライブラリとサーバーパッケージです。

## 内容

- すぐに利用できるリクエストベースのAPIライブラリ。
- HTTP API統合用サーバーコンポーネント。
- 動作するPlay Integrity Tokenソリューション。
- インストールと設定。
- 製品引き渡し時のトレーニング。

## 統合向け設計

HTTPリクエストでWhatsApp機能を既存システムへ接続します。製品資料では、アカウント登録、メッセージングワークフロー、通話、ボタン、プロフィール、グループをAPIで扱うことを説明しています。
