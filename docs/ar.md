# WhatsApp Core API

> **منتج تجاري**

حزمة متكاملة من مكتبة وخادم للعمل مع WhatsApp عبر HTTP API.

## ما الذي تتضمنه الحزمة

- مكتبة API جاهزة للاستخدام تعتمد على الطلبات.
- مكوّن خادم للتكامل عبر HTTP API.
- حل Play Integrity Token يعمل.
- التثبيت والتهيئة.
- تدريب عند تسليم المنتج.

## مصمم للتكامل

تربط الحزمة قدرات WhatsApp بأنظمتك عبر طلبات HTTP. توضح مواد المنتج تسجيل الحسابات وتدفقات الرسائل والمكالمات والأزرار والملفات الشخصية والمجموعات عبر API.
